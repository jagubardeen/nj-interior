# NJ Interior — GitHub Pages

Static GitHub Pages-ready website for NJ Interior.

## Files

- `index.html` — main page
- `css/style.css` — all page styling
- `js/script.js` — project rendering, modal, chatbot, form and scroll animation

## Publish on GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, the `css` folder and the `js` folder to the repository root.
3. Make sure the file is named exactly `index.html`.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select your main branch and `/ (root)`.
7. Save and wait for GitHub Pages to deploy.

No Node.js, React, Vite or build command is required.

## Important

The website currently uses Unsplash image URLs, so an internet connection is required for those remote images.

Replace the sample phone number, email address and WhatsApp number in `index.html` before publishing.
